# Fuentes / Fonts

Los `.ttf` no vienen en el repo. Se bajan de Google Fonts (licencia OFL-1.1) con `sh biblioteca/fuentes/preparar.sh`, que también revisa su sha256. Si agregas otra familia, anota cada archivo en `biblioteca/LICENCIAS.md`.

The `.ttf` files are not in the repo. Download them from Google Fonts (OFL-1.1) with `sh biblioteca/fuentes/preparar.sh`, which also checks their sha256. If you add another family, register each file in `biblioteca/LICENCIAS.md`.
