# Stickers

- `logos/`: logos de marcas que nombras, hechos con `npx tsx herramientas/stickers/logo.ts --marcas a,b` desde Simple Icons (CC0) o svgl (MIT). Sin recolorear ni deformar. / Brand logos from Simple Icons (CC0) or svgl (MIT), never recolored or distorted.
- `propios/`: tus PNG (dibujos, recortes, lo que tengas con licencia), procesados con `npx tsx herramientas/stickers/procesar.ts <carpeta> --destino biblioteca/stickers/propios` (macOS). / Your own PNGs, processed on macOS.

Cada archivo lleva su fila en `biblioteca/LICENCIAS.md`. / Every file gets its row in `biblioteca/LICENCIAS.md`.
